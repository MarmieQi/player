# 管理后台界面

- `admin-theme.css`：登录页和后台共享的主题色、文字及背景基础样式，仅作用于对应根类。
- `AdminLogin.vue`：登录表单、验证中状态、密码显隐及错误提示；登录请求仍由应用负责。
- `navigation.js`：菜单元数据及已有页面到菜单的映射；不依赖 Vue、接口或任务状态。
- `AdminLayout.vue`：桌面侧栏、平板折叠、手机抽屉和键盘交互。只接受展示数据，通过 `navigate` / `logout` 向外传达操作。
- `admin.css`：后台视觉规则，所有选择器限定在 `.admin-workspace` 下。
- `App.vue` 的 `navigateAdmin`：将菜单意图适配到现有页面加载函数；查询和任务的数据逻辑仍由原有函数负责。
- `log-feature-navigation.js`：日志查询、矿透分析及分析详情的独立地址和解析；兼容旧详情链接。
- `LogQueryTabs.vue`：只提供坐标查询和综合筛选，不承载矿透分析入口。
- `AdminSelect.vue`：后台共用的服务器及分页选框，保留选项值的原始类型；只发出值更新事件，不执行请求。菜单通过 Teleport 避免被表格裁切，按可用空间向上或向下展开，支持方向键、Home/End、Enter、Escape 和点击外部关闭。全局监听仅在展开期间注册。

日志查询使用 `logQueryPage` / `#/log-query`，矿透分析使用 `xrayAnalysisPage` / `#/xray-analysis`。两个页面复用任务加载和既有缓存，不互相提供页内切换入口；普通查询方式单独记忆，返回日志查询时保留。地址携带服务器与查询方式，刷新能恢复对应功能。

组件按需加载：`AdminLogin` 只在验证登录状态或未登录时挂载，`AdminLayout` 只在登录后的后台分支挂载。公开报告不挂载二者，不加载后台样式。新增菜单应同时补全页面映射和应用中的导航处理，避免将业务请求放进布局组件。

响应断点：桌面 ≥ 1200px；平板 768–1199px（默认收起，可展开）；手机 < 768px（抽屉）。抽屉打开时锁定背景滚动和交互，支持遮罩、Escape、焦点循环及关闭后焦点返回。

验证命令：`npm test`、`npm run build`。交互检查应覆盖各页面入口、任务服务器切换、查询条件保留、手机宽度及公开页隔离；避免在视觉验证中启动真实同步、导入或配置写入任务。
